# Green Grass Picker

A minimal, beautiful app to help you choose your next city to live and work remotely, based on your personal preferences.

## Features
- Drag-and-drop to rank your most important criteria (weather, safety, cost, etc.)
- See city rankings update instantly based on your preferences
- Clean, pastel-themed UI with Material UI
- Ready for deployment on GitHub Pages

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production (with correct base for GitHub Pages)
npm run build
```

## Deployment
This app is automatically deployed to GitHub Pages from the `gh-pages` branch using GitHub Actions.

Visit: [https://spattanaik75.github.io/green-grass-picker](https://spattanaik75.github.io/green-grass-picker)
